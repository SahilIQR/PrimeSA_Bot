# 🔐 Session Pairing

## ⚠️ IMPORTANT NOTICE

The **PrimeSA_Bot session website is currently being fixed and improved.**

The website may not work correctly during this period.

### 🟢 Temporary Method

While the session website is being fixed, you can temporarily use **another phone** to scan the WhatsApp QR code through your hosting panel.

If you are using **Katabump**, follow these steps:

### 📱 Step 1 — Use another phone

You will need **two phones**:

* 📱 **Phone 1:** The phone containing the WhatsApp account you want to connect to PrimeSA_Bot.
* 📱 **Phone 2:** The phone you will use to view the QR code from Katabump.

---

### 🌐 Step 2 — Open Katabump

https://rl.katabump.fr/3dcf50

Open your Katabump server/control panel and start PrimeSA_Bot.

Wait for the **WhatsApp QR code** to appear in the console.

---

### 📷 Step 3 — View the QR code

Use the second phone to take a clear picture of the QR code displayed by Katabump.

Make sure the **entire QR code is visible**.

---

### 🔗 Step 4 — Link the device

On the phone containing your WhatsApp account:

**WhatsApp → Settings → Linked Devices → Link a Device**

Then scan the QR code displayed by Katabump.

---

### ✅ Step 5 — Wait for the connection

After scanning the QR code successfully, wait for PrimeSA_Bot to connect.

You should eventually see something similar to:

```text
PrimeBot connected successfully!
```

Once connected, your WhatsApp account is linked and you can start using the bot.

# ⚠️ SECURITY WARNING

## 🚨 NEVER SHARE YOUR SESSION OR LOGIN CREDENTIALS

Your WhatsApp session credentials are **private**.

Never send or publish:

* ❌ Session IDs
* ❌ `creds.json`
* ❌ Authentication files
* ❌ QR codes
* ❌ Pairing codes
* ❌ API keys
* ❌ `.env` files
* ❌ Session folders

These credentials may allow someone else to access your bot session.

### 🔒 Keep your `.env` private

**NEVER upload your real `.env` file to GitHub.**

Your `.gitignore` should contain:

```gitignore
.env
sessions/
auth_info/
creds.json
*.session
```

If you accidentally expose your session credentials, immediately remove/revoke the affected WhatsApp linked session and create a new one.

# 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/SahilIQR/PrimeSA_Bot.git
```

### 2. Enter the project directory

```bash
cd PrimeSA_Bot
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure your environment

Create a `.env` file:

```env
SESSION_ID=your_session_id
SESSION_API_URL=
SESSION_API_KEY=
SESSIONS_DIR=./sessions
ANTI_DELETE_DEBUG=false
```

### 5. Start the bot

```bash
npm start
```
